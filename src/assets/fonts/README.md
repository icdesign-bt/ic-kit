# Moscow Sans W

Корпоративный шрифт дизайн-системы KURS v2. Входит в UI Kit **по умолчанию** — потребителю не нужно подключать шрифт отдельно, достаточно импорта `ic-kit/styles.css`.

| Файл | font-weight | Figma style |
|------|-------------|-------------|
| `MoscowSansW-Light.otf` | 300 | Light |
| `MoscowSansW-Regular.otf` | 400 | Regular |
| `MoscowSansW-Medium.otf` | 500 | Medium |
| `MoscowSansW-Bold.otf` | 700 | Bold |
| `MoscowSansW-Extrabold.otf` | 800 | ExtraBold |

CSS: [src/styles/fonts.css](../../src/styles/fonts.css) — `font-family: "Moscow Sans W"`.

Входит в пакет `ic-kit` и подключается через `ic-kit/styles.css`.
