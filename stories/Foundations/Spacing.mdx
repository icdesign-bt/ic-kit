# Spacing

В Figma DS — шкала `spacing/1` … `spacing/64`. В коде пока экспортированы ключевые значения в `tokens.css`:

| Token | Значение |
|-------|----------|
| `--spacing-16` | 16px |
| `--spacing-40` | 40px |

Компоненты используют эти и локальные токены (например `--tooltip-padding`, `--badge-gap`).

Для отступов в прототипах используйте flex/grid и `gap: var(--spacing-16)` (и другие `--spacing-*` из токенов).
