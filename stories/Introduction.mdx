# ic-kit

**UI Kit** дизайн-системы [KURS v2](https://www.figma.com/design/XFvebxoecl7DX4Oxm9GVJO/KURS-v2.-Components) — React-компоненты, токены, шрифт Moscow Sans W и иконки для прототипов в стиле **ИЦ** и **ЦОДД**.

Эта витрина — каталог компонентов и foundations. Чтобы подключить кит в свой Vite-проект, Storybook **не нужен** — см. документацию в репозитории:

- [README](https://github.com/icdesign-bt/ic-kit/blob/main/README.md) — установка, бренды, prompt для Cursor
- [installation.md](https://github.com/icdesign-bt/ic-kit/blob/main/docs/installation.md) — troubleshooting, обновление версии, шаблон `examples/vite-starter`

## Для кого

- **Сотрудники ИЦ** — прототипы и демо в Vite + React или Cursor (вайбкодинг)
- **Дизайнеры и PM** — посмотреть, как компоненты DS выглядят в коде

Кит для **прототипов**, не для production.

## Что смотреть здесь

| Раздел | Зачем |
|--------|--------|
| **Foundations** | Цвета, типографика, [иконки](?path=/story/foundations-icons--gallery) |
| **Components** | Все компоненты с состояниями и примерами |
| **Guides** | [Form composition](?path=/story/guides-form-composition--contact-form) — пример сборки формы |

В toolbar переключайте **Brand** (ИЦ / ЦОДД) и **Theme** (light / dark) — stories обновятся под выбранную палитру.

## Что в пакете

- Компоненты — Button, TextField, Select, Dialog, Tabs, Alert, Badge, Icon и др. (раздел **Components**)
- Токены — CSS-переменные для цветов, отступов, типографики
- **661 иконка** — `<Icon path="Category/Name" />`

Макеты в Figma: [KURS.Storybook](https://www.figma.com/design/wy9jtzeCE5LWQp3KIueIMM/KURS.Storybook?node-id=3-1215).
